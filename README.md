Problem:
Osoby uprawiające warzywa i owoce często nie wiedzą, dlaczego ich rośliny źle rosną, jak im pomóc ani jak efektywnie zaplanować ogródek.

Użytkownik:
Produkt jest dla osób początkujących - niepewnych jak zadbać o swój ogród oraz dla tych bardziej doświadczonych - chcących polepszyć swoje plony.

Trzy najważniejsze funkcje:
AI analiza stanu rośliny - określenie występujących chorób oraz braków
Planer ogródka
Katalog roślin - ich najlepszych warunków i sposobów pielęgnacji
